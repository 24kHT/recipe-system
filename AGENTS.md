# Project Instructions

This is a frontend/backend course project (食光菜谱系统 - Shiguang Recipe System).

Tech stack: Vue 3 + Vite 6 + Element Plus (frontend), Spring Boot 3.3.7 + MyBatis-Plus 3.5.9 + MySQL 8.4 (backend), JWT authentication.

When the user asks for PPT, PowerPoint, slides, slide deck, presentation, course report, project report, architecture diagram, ER diagram, flowchart, sequence diagram, API flow diagram, or database design slides:

- Use the local `ppt-project-report` skill in `.agents/skills/ppt-project-report/SKILL.md`.
- Generate a real `.pptx` file whenever possible.
- Use Mermaid for ER diagrams, flowcharts, routing diagrams, and sequence diagrams.
- Use PptxGenJS for generating native PowerPoint files.
- Use Python matplotlib and SciencePlots for scientific or technical charts when needed.
- Keep diagram source files and exported images.
- The presentation should be suitable for a university course report.

Recommended slides:
1. Title page
2. Project background
3. Requirements analysis
4. System architecture
5. Frontend routing
6. Backend architecture
7. Database ER diagram
8. Core business flow
9. API design
10. Feature demo
11. Testing and results
12. Summary and future improvements
